# Naufal Zaky Purwanto – Portofolio

Website portofolio satu halaman untuk Naufal Zaky Purwanto, Graphic Designer.
Tema putih, hitam, dan kuning, dengan pilihan bahasa Indonesia dan Inggris.

## Struktur
- `index.html` – halaman utama (HTML, CSS, dan JavaScript dalam satu file)
- `img/` – gambar karya
- `vid/` – video karya (Ads dan Motion graphic)
- `Naufal_Zaky_Purwanto_CV.pdf` – CV

## Menjalankan
Buka `index.html` di browser, atau jalankan server statis, misalnya:

```
python3 -m http.server 8000
```

Lalu buka http://localhost:8000
